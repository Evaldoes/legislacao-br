# Art. 804

Dar-se-á conflito de jurisdição:

## <a id="al-a"></a>Alínea a

quando ambas as autoridades se considerarem competentes;

## <a id="al-b"></a>Alínea b

quando ambas as autoridades se considerarem incompetentes.
