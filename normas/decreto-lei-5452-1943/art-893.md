# Art. 893

Das decisões são admissíveis os seguintes recursos:

## <a id="inc-1"></a>Inciso I

embargos;

## <a id="inc-2"></a>Inciso II

recurso ordinário;

## <a id="inc-3"></a>Inciso III

recurso de revista;

## <a id="inc-4"></a>Inciso IV

agravo.

## <a id="par-1"></a>§ 1º

Os incidentes do processo são resolvidos pelo próprio juízo ou tribunal, admitindo-se a apreciação do merecimento das decisões interlocutórias sòmente em recurso da decisão definitiva.

## <a id="par-2"></a>§ 2º

A interposição de recurso para o Supremo Tribunal Federal não prejudicará a execução do julgado.
