# Como contribuir

Obrigado pelo interesse em ajudar! 🎉

## Reportar uma divergência no texto

Se um arquivo estiver diferente do texto oficial, [abra uma issue](../../issues) com:

1. O arquivo (por exemplo, `normas/constituicao-1988/art-005.md`)
2. O trecho que está errado
3. O link da fonte oficial que mostra o texto correto

## Pedir uma nova lei

Abra uma issue com o nome e o número da norma (por exemplo, *"Lei nº 8.078/1990 – Código de Defesa do Consumidor"*) e o link dela no [Portal da Legislação](https://www.planalto.gov.br/legislacao).

## Pull requests

- **Não edite o texto da lei à mão** para "melhorar" a redação. O conteúdo deve ser idêntico ao texto oficial em vigor.
- Correções de divergência são bem-vindas. Cite a fonte oficial na descrição do PR.
- Melhorias na documentação (README, exemplos de uso) são sempre bem-vindas.
- Um assunto por PR.

## Formato dos commits

Atualizações de texto legal indicam a norma que causou a mudança:

```
constituicao-1988: atualiza art. 7º conforme EC 72/2013
```

Outras mudanças seguem o padrão `tipo: descrição`:

```
docs: adiciona exemplo de uso em Go
```

## Código de conduta

Seja respeitoso. Discussões sobre a interpretação ou o mérito político das leis estão fora do escopo deste repositório: aqui o assunto é o **texto**.
